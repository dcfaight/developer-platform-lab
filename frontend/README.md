# Frontend

React + TypeScript + Vite portal starter. Requires Node.js 24 and npm 11.

From this directory:

```sh
npm ci
npm run dev
```

Open http://localhost:5173. Use `npm run lint` and `npm run build` to validate.
The page is static: there are no API calls, environment forms, or polling yet.
Reserved source directories follow the root README's blueprint.
